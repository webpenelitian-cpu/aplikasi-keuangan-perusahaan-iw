Pemberitahuan privasi (UU 27/2022 tentang Pelindungan Data Pribadi) Dengan masuk, data keuangan yang Anda catat, termasuk data karyawan dan vendor (nama, NIK, NPWP, rekening, upah), disimpan di Google Cloud Firestore (pusat data Jakarta) dan data login (username/email) dikelola Google Firebase Authentication, hanya untuk menjalankan aplikasi ini. Perusahaan Anda bertanggung jawab atas data karyawan yang dimasukkan. Data hanya dapat diakses oleh akun Anda sendiri dan anggota perusahaan yang Anda undang sesuai perannya, tidak dijual, dan tidak dibagikan ke pihak lain. Bila kata sandi enkripsi dipasang, isi data terenkripsi sebelum dikirim. Anda dapat mengunduh (Backup) atau menghapus akun beserta seluruh datanya kapan saja di menu Atur → Akun.

Sesi dikunci

Akun tidak dipakai lebih dari 1 jam, dan perangkat sedang offline.

Isian yang belum terkirim tetap aman di perangkat ini. Sambungkan internet; aplikasi akan mengirimnya, lalu meminta Anda masuk kembali.

Akun & Penyimpanan Server

Keamanan

Tutup Buku & Jejak Audit

Setelah laporan suatu periode diserahkan (pajak, AHU, atau pemeriksa), tutup bukunya agar data tidak bisa diubah. Membuka kembali periode wajib disertai alasan dan tercatat di jejak audit.

Backup & Pulihkan

Simpan seluruh data ke file, atau pulihkan dari file backup. Bila kata sandi terpasang, file backup ikut terenkripsi. Di HP, file bisa langsung dikirim ke Google Drive atau aplikasi File. Catatan dan dokumen pembukuan wajib disimpan minimal 10 tahun (UU KUP Pasal 28 ayat 11).
